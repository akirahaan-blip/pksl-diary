# ポケスリダイアリー（pksl-diary）

ポケモンスリープ（pksl）の毎日を、スクショと一言で残す**自分だけの日記帳**。
Twitter みたいに書けるけど、見るのは自分だけ。スマホで使うのがメイン。

## できること

- 開いた瞬間は**今日のページ**。◀ ▶ で前後の日にめくれる
- 1日に**スクショ4枚**まで。タップで拡大、左右スワイプで次の1枚へ。スクショ下の ◀ ▶ で順番の入れ替え
- スクショの下に**日記の文章**。書いた瞬間に自動保存（保存ボタンなし）
- **タイムライン**：全部の日記を新しい順にスクロールして見返す。上の検索ボックスでキーワード検索（スペース区切りで絞り込み、カタカナ/ひらがな・大文字/小文字の違いは無視、「満月」「新月」でその日の日記も出る）
- **ランダムにふりかえる**：タイムラインの見出しの右のボタンで、日記かスクショがある日のどこかへ飛べる（いま開いている日は選ばれない）
- **カレンダー**：日記がある日にリングに1枚目のスクショ。満月・新月の日には小さな月の印、その前後1日には同じ印が薄く付く（設定で消せる／上弦・下弦も出せる）。日付を押すとその日へ
- **月まとめ画像**：カレンダーの月の帯の「🖼 まとめ」で、その月をカレンダーの形にした1枚の画像（PNG）を作れる。日記がある日のマスには1枚目のスクショが入る。絵日記と同じく X に投稿／保存できる
- **月の満ち欠け**：日付ページにその日の月の名前（新月・三日月・上弦・十三夜・満月・十六夜・下弦・有明月）。天文学の式で計算しているので通信不要
- **絵日記にする**：上にメインのスクショ、下に原稿用紙ふうの縦書き文章、という1枚の画像（PNG）にして、X に投稿したり保存したりできる
- **おこづかい帳**（💰タブ）：睡眠リサーチ結果のスクショを読み取って、リサーチEXP とゆめのかけらを記録する。
  - 「リサーチランクがカンストしている」にチェックすると、リサーチEXP もゆめのかけらとして足す（チェックは覚えておく）
  - 「使った」に切り替えると出費（レベル上げなど）も記録できる
  - 上に手持ちの残り、先月・今月の稼ぎ（横並び）、今週（月曜はじまり）の稼ぎと1日あたりの平均（今週すでに過ぎた日数で割る）
  - 睡眠リサーチを記録した日は、カレンダーに紫の印が付く。印は「色・設定」で選べる：♡ ハート（日付の数字をかこむ）／✓ チェック（日付の丸の右下）／表示しない（入れ忘れた日がひと目で分かる）
  - おこづかい帳のタブだけ、文字は教科書体ふうの Klee One、色ははじめメタモンっぽい薄紫（「色・設定」の「おこづかい帳の色」で好きな色や「ダイアリーと同じ色」に変えられる。カレンダーの印もこの色）
  - 「✨ 手持ちを入れる（スキル分）」で、ゲームの数 − 記録から計算した手持ち を自動で計算する。差が＋なら「ゆめのかけらゲット」スキルでもらった分として記録し、稼ぎに入れる（先月・今月の欄に「うちスキル」も出る）。差が−なら、ずれを直す記録になる
  - 「🔧 手持ちを入れる（ミッション分など）」は、スキル以外で数がずれたとき用。差は＋でも−でも「手持ちを合わせた」記録になり、スキル分や稼ぎには入れない
  - 読み取りは Tesseract.js（ブラウザの中だけで動く文字読み取り）。初回だけネットから読み込む。スクショは保存しない
  - 記録は localStorage（日記とは別の置き場）。バックアップの「書き出す」に一緒に入る。「日記をすべて削除」では消えない
- **設定**：テーマ色（好きな色に変えられる）／明るい・暗い／バックアップ

## ファイル

| ファイル | 役目 |
|---|---|
| `index.html` | アプリ本体（見た目・動きぜんぶ入り） |
| `manifest.json` / `icon-*.png` | スマホの「ホーム画面に追加」用の名前とアイコン |
| `サイトを開く.bat` | ダブルクリックでパソコンのブラウザで開く |
| `スマホで見る.bat` | 同じ Wi-Fi のスマホから開くための簡易サーバーを起動する |
| `serve-for-phone.ps1` | ↑の中身（直接さわらなくてよい） |
| `make-icons.py` | アイコンを作り直したいときだけ使う |
| `ogp.png` / `make-ogp.py` | X や LINE に URL を貼ったときに出るカード画像と、それを作るスクリプト |

## データはどこに保存される？

**開いたブラウザの中**（IndexedDB という置き場）に保存されます。
インターネット上には一切送られません。

注意：**開き方（URL）が違うと、別のノートになります。**
たとえば「パソコンでダブルクリックで開いたとき」と「スマホで URL から開いたとき」は
別々の保存場所です。引っ越したいときは、設定 → 「書き出す」→ 別の端末で「読み込む」。

ブラウザの履歴やサイトデータを全消去すると日記も消えるので、
**ときどき「書き出す」でバックアップ**を取っておくのがおすすめです。
